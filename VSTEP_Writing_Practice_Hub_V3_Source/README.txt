IELTS Writing Practice Hub V3
=============================

Files
-----
- IELTS_Writing_Practice_Hub_Mobile_v3.html
  Full standalone source code for the app, including:
  * Vocabulary practice (8 topics)
  * Grammar structures
  * Linking words and expressions
  * Common grammar mistakes
  * Writing Outline Builder
  * 23 IELTS Writing Task 2 prompts and idea banks
  * Responsive layout for laptop and mobile

Run on Windows
--------------
1. Extract the ZIP file.
2. Double-click IELTS_Writing_Practice_Hub_Mobile_v3.html.
3. If asked, choose Google Chrome, Microsoft Edge, or Firefox.

Run on macOS
------------
1. Extract the ZIP file.
2. Right-click the HTML file and choose Open With > Safari, Chrome, or Firefox.

No installation, Python, Node.js, or internet connection is required.

Edit the source
---------------
1. Open the .html file in Visual Studio Code, Notepad++, or another code editor.
2. HTML controls the page structure.
3. The <style> section controls colors, spacing, and responsive layout.
4. The <script> section contains the app logic and question data.
5. Save the file, then refresh the browser tab to see changes.

Important
---------
- This is a standalone browser app, not a server-hosted website.
- Saved outlines use the browser's localStorage on that device/browser.
- Clearing browser site data may erase saved outlines.
- To transfer saved outlines to another device, use the app's copy feature.
